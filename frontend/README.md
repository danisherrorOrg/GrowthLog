# GrowthLog Frontend

React frontend for GrowthLog personal growth tracker.

## Setup

```bash
npm install
```

## Run

```bash
# Make sure backend is running on localhost:8000
npm start
```

Open http://localhost:3000

## Environment Variables (optional)

Create a `.env` file:
```
REACT_APP_API_URL=http://localhost:8000
```

## Pages

- `/login` — Sign in
- `/register` — Create account
- `/dashboard` — Overview, heatmap, stats
- `/log` — Daily check-in
- `/growth` — Charts and analytics
- `/goals` — Goal tracking with reflection
- `/manifestations` — Vision and manifestation cycles
- `/snapshots` — Before & after self portraits
- `/categories` — Manage life categories
